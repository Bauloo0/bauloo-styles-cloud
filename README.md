# Bauloo Styles Cloud

Styles published by bauloo for the **Bauloo Styles** Minecraft mod.
The mod reads `index.json` and downloads a pack the first time a player applies it.

- `index.json` - list of styles (id, category, name, SHA-256, size, date)
- `packs/` - the resource packs
- `previews/` - 256x256 preview images

Only the owner of this repository can add or remove styles.
